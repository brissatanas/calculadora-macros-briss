# Calculadora de Macros Briss

Aplicación web personal para registrar alimentos, calcular macronutrientes y consultar el progreso diario y semanal. Este proyecto se desarrolla paso a paso como práctica de programación y como parte de mi portafolio.

## Funciones principales

- Registrar alimentos por cantidad y unidad.
- Calcular calorías, proteínas, carbohidratos y grasas de los alimentos registrados.
- Organizar el consumo por tipo de comida: desayuno, comida, cena y colación.
- Consultar los totales diarios y el historial de alimentación.
- Crear y administrar alimentos y categorías personalizadas.
- Definir metas de calorías y macronutrientes y revisar el progreso.
- Consultar estadísticas y tendencias semanales.
- Exportar respaldos y restaurar información desde un archivo compatible.

> Las funciones disponibles pueden cambiar a medida que el proyecto siga evolucionando.

## Tecnologías

- **HTML5** para la estructura.
- **CSS3** para los estilos y el diseño adaptable.
- **JavaScript** para los cálculos, la interacción y el manejo de datos en el navegador.
- **Python** para un análisis complementario de datos exportados.

## Cómo ejecutar la aplicación

1. Descarga o clona el repositorio.
2. Abre `index.html` en un navegador web moderno.
3. Usa las secciones de la aplicación para registrar alimentos y consultar tus resultados.

Como esta versión funciona en el navegador y no necesita un servidor de aplicación, no requiere una instalación de dependencias para comenzar a usarla.

## Almacenamiento y privacidad

La versión actual guarda información de la aplicación en el almacenamiento local del navegador (`localStorage`). Por eso, los datos no se sincronizan automáticamente entre dispositivos ni navegadores.

Los respaldos exportados y los archivos de análisis pueden contener información personal. **No publiques respaldos, registros de alimentación ni archivos CSV con datos reales.** Antes de compartir el proyecto, utiliza datos ficticios para las demostraciones y revisa los archivos que vas a subir al repositorio.

## Análisis complementario con Python

El proyecto incluye `analizar_macros.py` para realizar análisis complementarios a partir de datos exportados. Los archivos generados por el análisis pueden incluir tablas, informes y gráficas. Los datos reales deben mantenerse fuera del repositorio público.

## Alcance actual

Esta es una aplicación web en desarrollo. La versión actual no incluye autenticación de usuarios, una API propia ni una base de datos remota. Los datos se almacenan localmente en el navegador.

## Nota importante

Los valores nutricionales y los cálculos son estimaciones basadas en los datos introducidos. La aplicación tiene fines informativos y de seguimiento personal; no sustituye la orientación de un profesional de la salud o de nutrición.

## Estado del proyecto

El proyecto continúa en desarrollo. Se planean mejoras progresivas en la organización del código, la experiencia de usuario, la documentación y su publicación para demostración.
